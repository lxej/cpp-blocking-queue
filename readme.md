Учебная блокирующая очередь на C++17: mutex, condition_variable, тестирование и отладка
g++ -fsanitize=thread -O0 -g -std=c++17 tests.cpp BlockingQueue.cpp -o prog
./prog - запуск программы.
gdb ./prog - запуск отладчика.

Написал блокирующую очередь и юнит-тесты к ней.
Столкнулся с проблемой, из-за которой программа падала по segfault
после добавления многопоточного теста. С помощью gdb нашёл ошибку, она была
в том, что обращался по несуществующему индексу у received,
создал вектор с нужным размером и всё заработало, с ThreadSanitizer прогнал программу и
гонок данных не обнаружил.
